A simple Umbraco property editor that allows you to pick icons from Flaticon.com directly within the Umbraco backoffice.

Installation
------------
1. Download the package from the Umbraco Marketplace or GitHub repository.
2. in Master cshtml layout file, add reference flaticon css added in `wwwroot/App_Plugins/uThemesFlaticonPicker/assets/flaticon.css`
3. This will be  reference css for icons to display icon on views
